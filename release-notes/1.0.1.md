## 📊 What's New — bStats Integration

SkCine now includes support for **bStats**, an anonymous statistics platform for Minecraft plugins.

With this integration, we can better understand SkCine's adoption and improve future development.

**New statistics include:**
- 🌐 **Server Statistics** — Track how many Minecraft servers are running SkCine.
- 👥 **Player Statistics** — View the number of online players across reporting servers.
- 🎮 **Minecraft Versions** — Understand which Minecraft versions are most widely used.
- 📦 **Plugin Versions** — See which versions of SkCine are currently installed.
- 📈 **Usage Trends** — Follow SkCine's growth over time through the bStats dashboard.

### 🔒 Privacy & Control

The integration uses bStats' standard anonymous reporting system.

- No player names or chat messages are collected by SkCine's metrics integration.
- Server owners can disable metrics collection.
- Metrics can be controlled through `plugins/SkCine/config.yml` or the global bStats configuration.
- Statistics reporting runs independently of SkCine's cinematic engine.
- Metrics initialization failures will not prevent SkCine from starting.

## ⚙️ Technical Changes

This release also includes the underlying infrastructure required for bStats integration:

- Added `bstats-bukkit` dependency.
- Integrated metrics initialization into the plugin lifecycle.
- Added configuration options for enabling or disabling metrics.
- Relocated bStats classes to SkCine's private namespace using Gradle Shadow.
- Added ProGuard compatibility rules to protect the bundled metrics implementation.

The existing Skript syntax, camera systems, timelines, actors, and other cinematic functionality remain unchanged.

## 🛠️ Configuration

Server owners can control metrics through:

`plugins/SkCine/config.yml`

```yaml
metrics:
  enabled: true
  plugin-id: 0
```

The Plugin ID is supplied by the SkCine distribution. A value of `0` disables reporting.

## 🎥 What Is SkCine?

SkCine is a powerful cinematic framework for Minecraft servers, designed specifically for **Skript developers**.

Create cinematic experiences using ordinary `.sk` files — without external editors, resource packs, or complicated configuration systems.

**Core features:**

- 🎥 Cinematic cameras with smooth movement, keyframes, and advanced easing.
- ⏱️ Timeline-based scene scripting, reusable sequences, and playback controls.
- 🧍 Animated actors, custom movement, and display entities.
- ✨ Particles, visual effects, cinematic transitions, and audio.
- 💬 Interactive dialogue, branching choices, and storytelling.
- 👥 Multiplayer cinematics and shared experiences.
- 🛡️ Player restoration, crash recovery, and performance safeguards.

## 📥 Installation & Updating

1. Download the latest `SkCine` JAR from this release.
2. Replace your existing SkCine JAR inside the server's `plugins/` directory.
3. Restart your Paper server.
4. Keep your existing Skript scenes — no scene syntax migration is required for this update.

**Requirements:** Paper 1.21.4+, Skript 2.16.0+, and an appropriate Java version for your Paper release.
